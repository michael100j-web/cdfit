Equation syntax
One definition per line, NAME=expression, as in Prism's user-defined equations. X is the independent variable and the last line must define Y. Any name that is never defined becomes a fitted parameter. Names are case-insensitive. Lines starting with ; are comments.
Operators: + - * / ^ and parentheses. Functions: EXP LN LOG SQRT ABS CBRT MIN MAX SIN COS TAN ATAN. Odd roots of negative numbers (e.g. ^(1/3)) return the real root.
